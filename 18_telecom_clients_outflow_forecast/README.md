# 📊 Предсказание оттока клиентов телеком-компании

## 📌 Описание задачи
Оператор связи хочет научиться прогнозировать отток клиентов. Если абонент попадает в группу риска, оператор предлагает ему промокоды и/или специальные условия для удержания.

**Цель:** Построить модель, которая сможет достоверно выявлять клиентов из группы риска (высокая вероятность ухода абонента); выявить ключевые факторы, влияющие на уход.

## 🛠 Стек технологий
* **Язык:** Python
* **Библиотеки:** Pandas, NumPy, Scikit-learn, CatBoost / RandomForest / Keras, Matplotlib, Seaborn.
* **Работа с данными:** SQLite, SQLAlchemy
* **Анализ:** Исследовательский анализ данных (EDA), Feature Engineering, обработка дисбаланса классов.

## 📂 Описание данных
Данные хранятся в базе SQLite (`database.sqlite`) и состоят из 4 таблиц:
* `contract`: информация о договорах (тип контракта, способ оплаты, срок).
* `personal`: персональные данные (пол, наличие партнера и детей).
* `internet`: информация об интернет-услугах (тип подключения, скорость).
* `phone`: информация об услугах телефонии.

## 📈 Результаты и метрики
* **Лучшая модель:** CatBoost
* **Качество на тестовой выборке:** 
  * ROC-AUC: **[0.864]**
  * F2-score: **[0.647]** (при вычисленном оптимальном пороге - 0.425)
* **Главный инсайт:**
  * Клиенты со сроками договоров 2-4 года уходят примерно в **3 раза** раза чаще, чем клиенты со сроками договоров 0,5-1,5 года.
* **Бизнес-рекомендации:**
  * *Проактивное удержание на сроках договоров 18-24 месяцев*:
    * за 3-6 месяцев до окончания 2-летнего контракта предлагать персональные скидки или апгрейд услуг;
    * внедрить триггерную рассылку с логикой: "Вы наш давний клиент --> Ваш контракт истекает через Х мес. --> Вот вам специальное предложение".
  * *Сегментация "ветеранов"*:
    *  клиенты с сроком 4+ года имеют отток всего 9% - это самая ценная группа;
    *  изучить их профиль: какие услуги они используют? почему остаются? масштабировать этот опыт на основную "группу риска" (2-4 года).
