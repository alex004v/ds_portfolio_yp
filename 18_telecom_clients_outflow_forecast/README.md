# Модель предсказания оттока клиентов телекоммуникационной компании

## Описание проекта
Оператор связи хочет научиться прогнозировать отток клиентов. Если абонент в группе риска (модель предсказывает высокую вероятность планирует ухода абонента), то будут приняты меры для удержания абонента (будут предложены промокоды и/или специальные условия).

## Описание данных
Данные хранятся в Sqlite — СУБД, в которой база данных представлена одним файлом. Она состоит из нескольких таблиц:
<ul>
  <li><strong>contract:</strong> информация о договорах</li>
  <li><strong>personal:</strong> персональные данные клиентов</li>
  <li><strong>internet</strong> информация об интернет-услугах</li>
  <li><strong>phone</strong> информация об услугах телефонии</li>
</ul>

## План выполнения проекта
<ul>
  <li>Загрузка данных</li>
  <li>Предобработка данных, исследовательский анализ данных</li>
  <li>Ввод новых переменных</li>
  <li>Обучение моделей</li>
  <li>Выбор лучшей модели и ее тестирование</li>
  <li>Анализ важности признаков, выбор наиболее важного признака, формирование предложений для бизнеса</li>
  <li>Общий вывод</li>
</ul>

## Выводы
Создана модель для прогнозирования оттока абонентов оператора связи.

Проведен анализ основных факторов оттока абонентов.

Данные рекомендации по удержанию абонентов.
