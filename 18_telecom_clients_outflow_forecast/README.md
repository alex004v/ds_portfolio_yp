# 📊 Предсказание оттока клиентов телеком-компании

## 📌 Описание задачи
Оператор связи хочет научиться прогнозировать отток клиентов. Если абонент попадает в группу риска, оператор предлагает ему промокоды и/или специальные условия для удержания.

**Цель:** Построить модель, которая сможет точно выявлять клиентов из группы риска (высокий Recall), и выявить ключевые факторы, влияющие на уход.

## 🛠 Стек технологий
* **Язык:** Python
* **Библиотеки:** Pandas, NumPy, Scikit-learn, CatBoost / RandomForest / Keras, Matplotlib, Seaborn.
* **Работа с данными:** SQLite, SQLAlchemy
* **Анализ:** Исследовательский анализ данных (EDA), Feature Engineering, обработка дисбаланса классов.

## 📂 Описание данных
Данные хранятся в базе SQLite (`database.sqlite`) и состоят из 4 таблиц:
* `contract`: информация о договорах (тип контракта, способ оплаты, срок).
* `personal`: персональные данные (пол, наличие партнера и детей).
* `internet`: информация об интернет-услугах (тип подключения, скорость).
* `phone`: информация об услугах телефонии.

## 📈 Результаты и метрики
* **Лучшая модель:** CatBoost
* **Качество на тестовой выборке:** 
  * ROC-AUC: **[0.88]**
  * F1-score: **[0.72]**
* **Главный инсайт:** Клиенты с помесячной оплатой и без привязки автоплатежа уходят в **[X]** раз чаще.
* **Бизнес-рекомендация:** Предлагать переход на годовой контракт со скидкой 15% клиентам со стажем менее 6 месяцев.
